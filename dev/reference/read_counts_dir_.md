# Read counts from a directory written by write_multiOmicDataSet_properties

Read counts from a directory written by
write_multiOmicDataSet_properties

## Usage

``` r
read_counts_dir_(counts_dir)
```

## Arguments

- counts_dir:

  Path to the `counts/` subdirectory.

## Value

A named list of data frames (and nested lists for sub-count types).
