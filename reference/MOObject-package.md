# MOObject: multiOmicDataSet object class for MOSuite

MOObject defines the multiOmicDataSet object class which is used in
MOSuite for differential RNA-seq and multi-omics analyses. Separating
the MOObject class definition from MOSuite allows for lightweight
installations in downstream workflows. See the website for more
information: <https://ccbr.github.io/MOObject/>. See the MOSuite website
for the most comprehensive documentation:
<https://ccbr.github.io/MOSuite/>.
